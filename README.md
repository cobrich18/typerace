# TypeRace

Гонка на скорость печати с режимами по словам, по времени и свободным заездом. Есть одиночная игра, комнаты по коду и быстрый поиск соперника. Регистрация не требуется.

## Правила заезда

- **По словам:** побеждает тот, кто первым напечатает заданное число слов.
- **На время:** результат определяется по числу правильно набранных символов в конце таймера. Если весь текст набран раньше, заезд завершается досрочно.
- **Свободный:** создатель комнаты завершает заезд кнопкой. Текст содержит до 1200 слов; если игрок набрал их все, заезд завершается автоматически.

В онлайн-комнате второй игрок подключается по ссылке или через быстрый поиск. После подключения создатель запускает общий обратный отсчет и только он может вручную завершить заезд. Гость может выйти из комнаты; выход во время гонки засчитывается как победа создателя. Одиночный заезд стартует обычной кнопкой.

## Запуск локально

Нужен Node.js 24.

```bash
npm ci
npm run build
npm start
```

Откройте `http://localhost:10000`. Для проверки: `npm test`.

## Render

1. В Render выберите **New → Blueprint** и подключите этот GitHub-репозиторий. Файл `render.yaml` создаст веб-сервис.
2. Render выполнит `npm ci && npm run build`, затем `npm start`.
3. После успешного деплоя откройте выданный адрес `*.onrender.com`.

Для создания веб-сервиса вручную используйте runtime **Node**, build command `npm ci && npm run build` и start command `npm start`. Сервер слушает `0.0.0.0` и порт из `PORT`.

Комнаты на Render хранятся в памяти одного процесса. При перезапуске или засыпании бесплатного сервиса активные комнаты исчезают. Для постоянного хранения и нескольких экземпляров потребуется внешняя база данных. Рекорды одиночной игры сохраняются в браузере.

Исходный Worker для Sites находится в `worker/`, веб-файлы в `web/`. Сборка помещает их в `dist/`; тот же игровой код используется на Render и Sites.
